This is the README.md for Final Act. It lists all the required dependencies for the environment, and how to run the website properly locally.


# DEPENDENCIES
These are the necessary dependencies for the environment. These must be installed for the website to run properly.
    npm install dotenv
    npm install express
    npm install axios


# RUNNING
To run the website on localhost:3000, you must use the below line to run it. Running the plain HTML file will not allow the website to interact with the API at all.
    node apitest.js
